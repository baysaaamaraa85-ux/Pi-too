# ADR-017: Цалингийн мөр ирцийн мөр бүрт нэг байна

* Төлөв: Батлагдсан (2026.10.29)
* Орлуулсан: ADR-010-ийг хэсэгчлэн (EARNING мөрийн нэгж хичээлээс ирцийн мөр болсон)
* Хамаарах шаардлага: ФШ-32, 34, 53, 54, 56, 57, 58, шинэ шаардлага 1.6

## Нөхцөл ба асуудал

ADR-010 багшийн цалинг зөвхөн нэмэгддэг гүйлгээний бүртгэлээр (ledger_entries) тооцохоор
шийдсэн. Тэнд хичээл бүрт НЭГ `EARNING` мөр бичигдэж, `UNIQUE(lesson_id)` хязгаарлалттай байв.
Энэ нь хоёр асуудал үүсгэсэн:

1. Админ цалингийн хуудсанд сурагч бүрийн нэрээр мөр харах шаардлагатай (нэг мөр = нэг сурагч).
2. Ирц засахад (Хүснэгт 3.15) ямар сурагчийн ирц өөрчлөгдсөнийг журналаас мөшгих боломжгүй.
   Нөхөлтийн сурагч хичээл бүртгэгдсэний дараа нэмэгдэхэд хичээлийн ганц EARNING мөрөнд
   нэмэх аргагүй (мөрийг засахыг ADR-010 хориглоно).

## Авсан хувилбарууд

| Хувилбар | Давуу тал | Сул тал |
| --- | --- | --- |
| A. Хичээл бүрт нэг EARNING (ADR-010) | Мөр цөөн | Сурагчаар задлах, нөхөлт нэмэх боломжгүй |
| B. Ирцийн мөр бүрт нэг EARNING (сонгосон) | Сурагч бүрийн мөр, засвар мөр бүрт мөшгигдөнө, нөхөлт тусдаа мөр | Мөр олон (30 багш x 25 ирэлт x 6 сурагч) |
| C. Ирцийн мөрийн дүнг хадгалахгүй, ирцээс тооцох | Давхар өгөгдөлгүй | Цалин түүхэн баримт биш болно, үнэлгээ өөрчлөгдөхөд хуучин дүн хувирна |

## Шийдвэр

B хувилбар. `ledger_entries.attendance_id` (nullable FK, `ON DELETE RESTRICT`) нэмсэн.

* `EARNING` мөр цалинд тооцогдох төлөвтэй (Ирсэн, Чөлөө хэтэрсэн, Нөхөлт) ирцийн мөр бүрт нэг.
  Хэсэгчилсэн `UNIQUE(attendance_id) WHERE type = 'EARNING'`. Хуучин `UNIQUE(lesson_id)` устсан.
* Нэг мөрийн дүн = `rate_used x үргэлжлэх хугацаа (цагаар)` (Decimal). Нэг хичээлийн мөрүүдийн
  нийлбэр ФШ-53-ын томьёо `үнэлгээ x тооцогдох сурагчийн тоо x хугацаа`-тай яг тэнцүү.
* Ирц засахад ADJUSTMENT мөр (тухайн `attendance_id`-тай) нэмэгдэнэ. EARNING мөр хэзээ ч
  өөрчлөгдөхгүй (ADR-010 хэвээр). Засварын дүн: `зорилтот дүн - тухайн ирцийн одоогийн нийлбэр`.
* `lesson_id` хэвээр үлдэнэ (хичээлээр бүлэглэх, шүүх).
* Хуучин өгөгдөл: нэг хичээлийн EARNING мөрийг тухайн хичээлийн цалинд тооцогдох ирцийн
  мөрүүдэд тэнцүү хуваасан (нийлбэр өөрчлөгдөхгүй). Хөрвүүлэлт migration-д.

## Үр дагавар

* Сайн: цалингийн хуудас сурагчаар задарна, нөхөлт, засвар тус тусдаа мөрдөгдөнө, 
  `SUM(amount)` үлдэгдэл өөрчлөгдөхгүй.
* Муу: журналын мөр 6 дахин олон. ФБШ-05 (10 секунд) хэмжилт, ТӨ-03-ын босгыг дахин шалгана.
* Тайландаа шинэчлэх: ADR-010 "Хэсэгчлэн орлуулсан (ADR-017)", Хүснэгт 3.9 (`ledger_entries`
  багана, хязгаарлалт), Хүснэгт 3.19, 4.2 (хэсэгчилсэн UNIQUE), 3.8.1-ийн 6-р алхам.
